# billing.spec.ts - テスト責任範囲

## テスト対象の責務

Billing ドメインモデルは**「受け取った値を確定する」**責務を持つ。

### ✅ テストする責務

1. **金額の正規化**：小数を切り捨てて整数化
2. **1円未満の拒否**：切り捨て後0円は受け入れない
3. **未来日付チェック**：支払期限が未来であること
4. **状態遷移**：DRAFT → CONFIRMED のみ許可
5. **不変性保証**：確定後、金額・期限・ユーザーIDは変更不可

### ❌ テストしない責務（他のレイヤの責任）

- 金額計算ロジック（料金計算、割引、税計算）
- 支払期限決定ロジック（何日後、営業日計算）
- 詳細な妥当性チェック（金額上限、詳細な日付検証）

## 設計原則

**「受け取った値を必ず確定する」**
- 金額・期限の決定は責任外
- 最低限のガードのみ実施（1円未満拒否、未来日付チェック）

## テスト実行

# テスト実行

# カバレッジ確認
npm run test:cov
